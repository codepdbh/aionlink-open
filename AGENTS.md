Read README.md and docs/PROGRESS.md before changes. Preserve user APK originals.
Use static analysis first; never execute third-party APKs, extract secrets or copy
proprietary source/native libraries into android/. Local extracted/ and analysis/
contain untrusted proprietary research, excluded from Git. Do not upload them.
Only independently authored code is GPL-3.0-or-later. Maintain evidence provenance
and distinguish static observations, hypotheses and hardware verification.
Never report pairing as an ICCOA session. Do not invent wire messages or UUIDs.
No vehicle installation, flashing, CAN writes, driving-system changes, bypasses,
private credentials or publication without explicit authorization. Hardware tests
require the owner present and vehicle parked. Do not interrupt the desktop.
Run Python tests and Android JVM tests/build when changing those components.
Record errors, tool versions, hashes and incomplete milestones in docs/PROGRESS.md.
